SINKRONISASI PRIBADI

Simpan di Google Sheets

Hubungkan Sheet pribadimu agar barang dan transaksi bisa dibuka dari laptop maupun HP.

Belum punya Client ID? Lihat cara menyiapkannya
  1. Buat project di Google Cloud Console, lalu aktifkan Google Sheets API.
  2. Atur Google Auth Platform / OAuth consent screen untuk akun pribadi dan tambahkan akun Google-mu sebagai test user bila diminta.
  3. Buat OAuth Client ID jenis Web application. Pada Authorized JavaScript origins, tambahkan https://kasir-kopma.vercel.app. Client ID bukan password; jangan pernah masukkan client secret di sini.
  4. Buat Google Spreadsheet pribadi yang kosong. Dari tautannya, salin ID di antara /d/ dan /edit.
Status: Belum terhubung
Setiap perangkat perlu pengaturan ini sendiri dan login dengan akun Google yang sama.

Jangan bagikan tautan atau akses Sheet kepada orang lain. Data laptop baru dikirim ke Sheet setelah memilih “Kirim ke Sheet”. Di HP, pilih “Ambil dari Sheet” untuk memuat data yang sama.

Untuk memindahkan data dari aplikasi file lokal ke situs Vercel, unduh cadangan di sini, buka situs Vercel, lalu pilih “Pulihkan cadangan”. Berkas cadangan hanya berisi barang dan transaksi, bukan pengaturan Google.
